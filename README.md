# Meezan Bank Project

This repository contains the Meezan Bank application with both frontend and backend components.

## Project Structure

- **meezanbank/** - Frontend application built with Oracle JET (JavaScript Extension Toolkit)
- **demo - Copy/** - Backend application built with Spring Boot (Java)

## Frontend (meezanbank)

### Technologies
- Oracle JET Framework
- Knockout.js
- RequireJS
- CSS3

### Setup
```bash
cd meezanbank
npm install
```

### Run
```bash
npm start
```

## Backend (demo - Copy)

### Technologies
- Java Spring Boot
- Maven
- H2 Database

### Setup
```bash
cd "demo - Copy"
./mvnw clean install
```

### Run
```bash
./mvnw spring-boot:run
```

## Features
- User Profile Management
- OTP Verification
- Account Information Display
- Edit Profile Functionality

## Installation

1. Clone the repository
2. Install dependencies for both frontend and backend
3. Run both applications concurrently
